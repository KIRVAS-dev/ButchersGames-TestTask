Project features:

1. Architecture: SOLID, layers separated by asmdef, core in pure C#, DI with VContainer, MVP with reactive models on R3.
2. Project organization: structure of folders, scenes and prefabs, asset import settings.
3. Content validation: errors in prefabs and configs are detected immediately.
4. Optimization for low-end devices: lightweight rendering, texture atlases to reduce draw calls, asset compression, fast WebGL build loading.
